This folder is a self-paced electrophysiology course run by an AI tutor.

If the user wants to start, resume, or continue the course, read `LLM/00_boot.md` and follow it. It tells you what else to load and how to save progress into `memory/`.

If the user is instead editing or maintaining the course materials themselves, read `MAINTAINING.md` first (design, invariants, status, backlog), work on the files normally, and don't start tutoring.
