# Lab context (optional; filled in by the lab, not the learner)

The core course is deliberately general. A lab can use this file to give the tutor local context **without editing the course itself**. Leave anything unknown blank. The tutor must never treat blank fields as permission to invent details.

The tutor uses this file only to:

- choose examples that match the learner's real setup;
- point the learner to the right local document or person;
- avoid generic advice that conflicts with local practice.

It never turns the tutor into a source of operational settings. Stimulation limits, coating recipes, and acceptance criteria still come from the SOPs listed here.
